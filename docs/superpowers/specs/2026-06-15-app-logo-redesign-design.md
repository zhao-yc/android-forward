# APP Logo 重设计说明

## 目标

为“通知转发”设计一套原创 APP 图标，清晰表达“通知从一部手机转发到另一部手机”，避免直接使用 Android、Apple 等第三方品牌 Logo。

## 视觉设计

- 使用 Image 2 生成的深色立体图标，保证图标在不同桌面壁纸上都有稳定轮廓。
- 左侧是带打孔前摄的通用安卓手机造型，屏幕显示绿色通知卡片。
- 右侧是带灵动岛的高端手机造型，屏幕显示蓝色通知卡片。
- 两部手机中间使用高亮橙色单向箭头，明确表达从左向右转发。
- 图标使用醒目的立体材质和强对比色，缩小后仍可辨认。
- 不使用任何厂商名称、商标、系统 Logo 或容易被误认为官方标志的图形。

## Android 资源

- 普通图标使用 Image 2 生成的 PNG 作为自适应图标彩色前景。
- 普通与圆形图标共用同一张彩色图标图片。
- 增加 Android 13 主题图标使用的单色矢量资源。
- 常驻通知栏状态图标保持现状，不在本次修改范围内。

## 验证标准

- 在常见圆形、圆角方形等启动器遮罩下，主体不会被裁切。
- 在大图标和约 48px 小图标下，都能识别出“两部手机”和“向右箭头”。
- Docker 执行 `assembleDebug` 成功，生成可安装 APK。
- 检查 Android 资源引用，确保普通图标、圆形图标和主题图标均可正常解析。
